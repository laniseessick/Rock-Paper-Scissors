# Rock, Paper, Scissors 🎮

A simple Rock, Paper, Scissors game I built with HTML, CSS, and JavaScript.

### 🎮 [Play the Game](https://laniseessick.github.io/Rock-Paper-Scissors/)

I wanted to build something small that would let me practice JavaScript, DOM manipulation, and CSS while also giving me a chance to make the UI my own.

## What It Does

You play against the computer by choosing Rock, Paper, or Scissors. The computer randomly chooses its move, and the game determines the winner.

The game keeps track of the score and lets you reset everything whenever you want to start over.

### Features

* Choose Rock, Paper, or Scissors
* Random computer selection
* Keeps track of player and computer scores
* Displays the current choices
* Shows whether you won, lost, or got a draw
* Reset button to start a new game
* Hover and click animations
* Custom game-themed UI

## Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome

## How to Play

1. Choose Rock, Paper, or Scissors.
2. The computer makes its choice.
3. The game determines the winner.
4. The score updates.
5. Keep playing or hit the reset button to start over.

### Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choice = Draw

## Running It Locally

If you want to run the project locally, clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/rock-paper-scissors.git
```

Then open `index.html` in your browser.
